LamaVPN Pro

A VPN that tells you exactly what it does with your traffic: nothing.

Built on the WireGuard protocol with keys generated and held inside the Android Keystore. No traffic logs, no DNS logs — just a fast, direct tunnel.

  • ✓WireGuard protocol for low-latency, modern encryption
  • ✓Hardware-backed key storage via Android Keystore
  • ✓Real free tier — not a 3-day trial disguised as one
  • ✓One-tap connect, MVVM architecture under the hood

Under the hood

Architecture

MVVM with Jetpack Compose, keeping connection state, server selection, and billing status cleanly separated so the UI never blocks on network calls.

Monetization

Freemium via AdMob and Google Play Billing — free users get a genuinely usable tier, Pro removes ads and unlocks the full server list.

Security posture

Private keys never leave the device's secure hardware. The app is designed so that even a compromised app process can't export a raw key.

What's still in progress

The backend API, WireGuard VPS fleet, and full auth flow are being built alongside the client — this page reflects the app's design, not a finished server network.
