Port Availability Reference & Tester

Common port reference list for network administrators:

  • Port 80: HTTP (Web Traffic) — Standard Unencrypted
  • Port 443: HTTPS (Secure Web Traffic) — SSL/TLS Enforced
  • Port 22: SSH (Secure Shell) — Remote Administration
  • Port 53: DNS (Domain Name System) — Name Resolution
  • Port 3306: MySQL Database Engine
