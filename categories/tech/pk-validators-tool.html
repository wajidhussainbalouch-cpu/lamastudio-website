Technical Specifications

This utility uses the official ISO 7064 MOD 97-10 algorithm with native BigInt calculations to process bank checksum verification and code generation entirely on your device.

Is a valid generated IBAN guaranteed to work?

Generated IBANs pass the correct mathematical MOD 97-10 standard based on your bank code and account number. However, actual fund transfers require the underlying bank account to be active and properly registered with the financial institution.
