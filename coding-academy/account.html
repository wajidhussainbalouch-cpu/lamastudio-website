Your privacy and choices

  • Learn, practice, and save your drafts locally without registering.
  • Email authentication is available only after a dedicated backend is configured. No admin password or secret service key belongs in the website.
  • Cloud progress is stored per account with database row-level access rules. Users cannot browse another learner's progress through the app.
  • Uploads and restores happen only when you press the corresponding button and confirm. Sign-out does not delete this device's local learning history.
  • Cloud backups may contain code and personal reflections. Do not type secrets or real student records into exercises. You can delete the cloud progress copy without deleting your local work.
  • Deleting a learner account is a separate, password-verified action available only when a protected backend has been deployed. It also deletes the associated cloud progress through a database foreign-key rule.
