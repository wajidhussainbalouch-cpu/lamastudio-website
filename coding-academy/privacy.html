Your code, your progress, your choices.

You can learn without signing in. The academy saves practice progress on this device. A future optional account may let you send a copy to a private cloud record, but cloud uploading is off by default and never happens automatically.

Development status: This describes the Coding Academy development implementation, not an activated cloud service or a finalized legal privacy policy. Before accepting registrations, the owner must verify applicable privacy requirements, publish support/deletion contact details, choose retention periods and test the backend.

1. What information is stored?

InformationWhereWhen
Completed lessons, quiz choices, code drafts and progressYour browser's local storageWhile learning, even without signing in
Optional portfolio descriptions and project draftsYour browser's local storageWhen you choose to write them

Cloud snapshot of four learning modulesPrivate user-owned database row, if enabledOnly when you tick consent, press Upload and confirm

Do not use real student records, passwords, financial records, API keys or sensitive information as example code or portfolio text.

2. Who can see cloud progress?

The prepared database uses row-level access rules based on the verified learner account, so one learner should not be able to query another learner's row. These rules are not active or independently verified until the dedicated Coding Academy database is configured and tested.

Cloud snapshots are not end-to-end encrypted by this app. Authorized backend administrators and service infrastructure may access them. Authentication and data processing may involve Supabase. A version-pinned external code host provides the optional Supabase browser library, and the Python runtime is downloaded from a separate CDN when used.

3. How to keep, move or remove your data

  • Export: Open My Learning Journey to download a local JSON backup. Keep it in a private place because it contains drafts and reflections.
  • Move devices: Restore your trusted JSON backup, or, after cloud activation, manually upload on one device and restore on another. Newer cloud copies are protected from accidental overwrite by an older device.
  • Delete from this browser: Use the local-data delete action on the Account & Data page. Confirming removes the four academy learning stores from this browser only.
  • Delete cloud progress only: A signed-in learner may delete their private cloud progress row without deleting the Auth account or browser data.
  • Delete the account: After a protected backend service has been configured and tested, email/password learners can confirm their current password and request permanent Auth account deletion. The linked progress row is removed by cascade. Browser data on each device is a separate choice.

Local data may also disappear when you clear browser storage, change browser profiles, use private browsing or uninstall an app. Any copies you exported or shared are not automatically erased by deleting a cloud record.

4. Children and guardians

The academy is designed for beginners of different ages, including young learners. Children should use local guest learning or involve a parent or guardian before creating an online account. Actual account eligibility, age requirements, parental permissions and retention policies must be decided and documented before the cloud service launches.

5. Account deletion and technical limitations

Account deletion is not the same as deleting one cloud backup. The prepared deletion function requires the signed-in learner's own password and uses a server-only administrative key; it is disabled until security checks are complete. Existing access tokens may remain valid until expiration, and infrastructure backups may follow the hosting provider's retention schedule. Do not claim instant removal from every backup.

The app does not currently implement automatic cloud merging, teacher monitoring, accredited certificates, paid subscriptions, or cross-product sharing with LAMA PPSC Academy or LAMA School Suite.
