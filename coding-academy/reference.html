HTML text formatting · Level 1

Learn 12 short examples in order. Read the meaning, compare the source code with the browser output, then predict the answers. Estimated study time: 15 minutes.

Remember: HTML describes meaning and structure. CSS controls appearance. The rendered examples below use real HTML, not screenshots.

Headings

1 / 12

h1, h2, h3 — Headings organize a page into sections; choose the level for its structure, not its size.

<h1>My school</h1>
<h2>Our classes</h2>
<h3>Class One</h3>
Browser output

Paragraph and line break

2 / 12

p, br — A paragraph groups text. A line break starts a new line inside a paragraph, such as in an address or poem.

<p>School Road<br>Pakistan</p>
Browser output

School Road
Pakistan

Strong importance

3 / 12

strong — Use strong for important, serious or urgent content. Browsers usually display it in bold.

<p><strong>Important:</strong> Bring a notebook.</p>
Browser output

Important: Bring a notebook.

Emphasis

4 / 12

em — Use em for stress emphasis that changes how a sentence is understood. Browsers usually display it in italics.

<p>I <em>really</em> enjoy coding.</p>
Browser output

I really enjoy coding.

Bold attention

5 / 12

b — Draw attention to a word without adding strong importance. Use CSS for purely decorative bold styling.

<p>Keyword: <b>HTML</b></p>
Browser output

Keyword: HTML

Alternate voice or term

6 / 12

i — Mark an alternate voice, technical term or another text convention, rather than general emphasis.

<p>The term <i>markup</i> describes tagged text.</p>
Browser output

The term markup describes tagged text.

Highlight

7 / 12

mark — Mark text relevant to the current context, such as a search result.

<p>Find <mark>coding</mark> lessons.</p>
Browser output

Find coding lessons.

Small print

8 / 12

small — Use for side comments or small print, such as a brief disclaimer.

<p>Free practice. <small>Terms apply.</small></p>
Browser output

Free practice. Terms apply.

Subscript

9 / 12

sub — Place a character below the normal baseline where the notation requires it.

<p>H<sub>2</sub>O</p>
Browser output

H2O

Superscript

10 / 12

sup — Place a character above the normal baseline, such as an exponent.

<p>5<sup>2</sup> = 25</p>
Browser output

52 = 25

Deleted and inserted text

11 / 12

del, ins — Show a document edit: removed text with del and inserted text with ins.

<p><del>Monday</del> <ins>Tuesday</ins></p>
Browser output

Monday Tuesday

Inline code

12 / 12

code — Identify a fragment of computer code. Escape angle brackets when teaching HTML tags.

<p>Use <code>&lt;p&gt;</code> for a paragraph.</p>
Browser output

Use <p> for a paragraph.

Predict before revealing · 6 questions

Think of an answer, then tap to reveal the explanation. This practice is independent of saved academy progress.

1. Which tag marks urgent information: b or strong?

strong — it conveys importance, not just visual attention.

2. How do you write the chemical formula CO₂?

Use CO<sub>2</sub>.

3. What is the difference between em and i?

em conveys stress emphasis; i identifies an alternate voice or convention.

4. Which heading should follow h1 for a major section?

h2. Heading ranks represent structure; avoid choosing a rank just for appearance.

5. How can you display a literal HTML tag in a lesson?

Escape its angle brackets, for example &lt;p&gt; inside a code element.

6. Which two elements indicate an edited word?

del for removed content and ins for added content.
