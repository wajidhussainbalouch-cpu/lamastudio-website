Important import rules

Existing student records are updated only when a matching enrollment ID is found. Nonmatching records are skipped; no new student is created. Existing values, including photographs, are preserved. Review the preview carefully and back up your data first. These operations use the same LamaAPI students collection as Manage Students and Admissions.
